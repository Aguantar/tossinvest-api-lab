# 05. 2주차: dbt 층 (2026-10-15)

목표: 원천 위에 "믿을 수 있는 숫자" 층. 판정(빈틈·일치·정정·커버리지)은 전부 여기서 하고, 수집기는 판정하지 않는다(docs/04).

## 1. 결정

| 결정 | 왜 |
|---|---|
| dbt-postgres, Oracle 의 같은 venv, cron 21:50 KST | 마감 순회(20:30, 72분) 뒤. 스케줄러는 아직 cron - "만든 것 ≠ 도는 것" 은 raw.run_log(job='dbt') 로 |
| 층 넷: staging(view) → dim → quality → mart | 코인 프로젝트와 같은 규약. staging 은 jsonb 를 열로 풀기만, 해석은 그 위에서 |
| 비밀은 env_var('PGPASSWORD') | profiles.yml 을 저장소에 넣기 위해. 값은 Oracle 의 .pgpass_toss 에만 |
| 세션 라벨은 봉 종료 시각으로 | ≤09:00 pre, ≤15:30 regular, 그 뒤 after. 10-14 봉 분포가 그 경계를 보여 준다(08:01 봉 604, 09:01·15:30 봉 4,304, 15:31 이후 2,492) |
| 프로파일은 관측값과 기대값 둘 다 | 관측(첫·마지막 봉)으로 720/660/390 을 정하고, 기대는 종목 속성(nxt_supported → 720)으로. 둘이 어긋나면 테스트가 막는다 |
| 종목 기본정보는 dbt snapshot(SCD2, check 전략) | 날짜별 스냅샷 표에서 직접 SCD2 를 짜는 것보다 "언제 바뀌었나" 를 도구가 기록하게 두는 것이 표준. 10-15 첫 버전 4,304행 |
| 정정 이력 = 연속한 두 스냅샷의 수정주가 종가 비교 | 바뀐 종목·바뀐 거래일 범위·비율 중앙값. 스냅샷이 둘 이상 있어야 행이 생긴다(10-15 저녁부터) |
| 마트 둘: 시장 일별(공개 가능) / 종목 일별(내부) | 약관. 시장 집계는 종목 이름·가격이 없고, 종목 마트는 DB 안에서만 |
| 추세 커버리지 테스트는 투자자별 매매만 | 공매도·프로그램·대차는 "없는 날이 정상"(50~67%), 신용은 하루 늦다. 투자자별만 전 종목(100%) |

## 2. 만든 것 (모델 18, 스냅샷 1, 테스트 15, 소스 신선도 14)

| 층 | 모델 | 한 행 |
|---|---|---|
| staging | stg_candles_1m, stg_candles_1m_intraday, stg_candles_1d_snapshot, stg_stock_info, stg_warnings, stg_investor_trading, stg_short_selling, stg_credit_trades, stg_sweep_manifest, stg_market_calendar | 원천 1행 = 1행 |
| dim | dim_symbol_day_profile (거래일 × 종목: 관측·기대 프로파일, 속성), dim_calendar | |
| snap | snap_stock_info (SCD2) | 종목 × 버전 |
| quality | dq_bars_daily (빈틈), dq_intraday_vs_final_daily (장중=마감), dq_adjustment_changes_daily (정정), dq_trend_coverage_daily (커버리지) | 거래일 (정정은 × 종목) |
| mart | mart_market_daily (공개 가능), mart_symbol_daily (내부) | 거래일 / 거래일 × 종목 |

싱귤러 테스트 4: 빠짐없음(관측 프로파일 대비 부족·빈틈·수집 오류 0), 프로파일 = 종목 속성, 장중 = 마감(둘 다 있는 날만), 투자자별 매매 커버리지 ≥ 99%(수집일만).

## 3. 첫 결과 (10-13·10-14)

| 표 | 값 |
|---|---|
| dq_bars_daily | 이틀 모두 부족 0, 빈틈 0, 오류 0, 프로파일 불일치 0. 720/660/390 = 604/1,892/1,808 → 604/1,888/1,812 (이틀 사이 4종목이 660↔390 이동) |
| dq_intraday_vs_final_daily | 10-14: 2,387,640 셀 100% 일치, 장중에 바뀐 봉 69,321. 10-13 은 장중 표 없음(폴링 전) |
| 프로파일 × 속성 (10-14) | 720 = nxt_supported 주식 604 전부. 390 = ETF 1,176 + ETN 368 + 주식 265. 660 = 주식 1,844 + 리츠 22 + DR 10 + 외국주 10. **프로파일은 데이터 성질이 아니라 종목 속성이다** |
| dq_trend_coverage | 투자자별 100%, 공매도 50%, 프로그램 58%, 대차 67%, 신용 76%(전날)·오늘 없음 |
| mart_market_daily | 경고 종목 34 (10-14), 프리마켓 참여 604, 애프터 2,492~2,496 |
| 테스트 | 처음 13/15: 장중=마감 테스트가 오늘(완결본 없음)을 잡았고, 커버리지 테스트가 시험 실행 잔재(10-05 이전 부분 적재)를 잡았다. 둘 다 테스트의 범위를 "둘 다 있는 날" "수집일" 로 좁혀 15/15 |

두 테스트 실패는 모델이 아니라 테스트 범위의 문제였고, 그 수정 자체가 "테스트가 막을 수 있는 건 그 시각에 판정할 수 있는 것뿐"(코인 docs/44 §13)의 재적용이다.
